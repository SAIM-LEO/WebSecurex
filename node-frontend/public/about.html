ABOUT & DOCUMENTATION

Final Year Project (FYP) — Automated Web Security Analysis Platform

Developed for the Bachelor of Science in Information Technology (BSIT)

System Intelligence

WebSecureX is an automated DAST (Dynamic Application Security Testing) platform that orchestrates industry-standard security engines to detect critical web vulnerabilities.

It is designed to simplify complex penetration testing workflows, providing developers and security students with a unified interface for vulnerability assessment.

Getting Started

  1. Enter a target URL (e.g., http://testphp.vulnweb.com) in the scanner dashboard.
  2. Select an Audit Depth:
    • Quick: Rapid check for common flaws.
    • Normal: Balanced depth and speed.
    • Deep: Full-scale crawl and heavy payload testing.
  3. Toggle Hacker Mode if you want to see the raw tool outputs in real-time.
  4. Click SCAN ALL to begin the multi-phase audit.

Integrated Engines

⚡

XSStrike (XSS)

Advanced XSS detection engine with multi-threaded crawling and context-aware payload generation. Capable of bypassing various WAFs and filters.

⭐ 14.8K GitHub Stars | Python | GPL-3.0

💉

sqlmap (SQL Injection)

The world's most powerful automated SQL injection tool. Fingerprints backend DBMS and tests all parameters with 6 injection techniques.

⭐ 32K GitHub Stars | Python | GPL-2.0

🔥

NoSQLMap (NoSQL)

Specialized tool for detecting injection and authentication bypass vulnerabilities in NoSQL databases like MongoDB, Redis, and CouchDB.

⭐ 2.8K GitHub Stars | Python | GPL-3.0

🔐

SSL Auditor (TLS/SSL)

High-performance certificate validator. Detects expired certificates, weak cipher suites, self-signed chains, and heartbleed vulnerabilities.

⚡ Built-in Engine | Python SSL Engine | Secure

🛰️

IP Reputation (Threat Intel)

Real-time integration with AbuseIPDB. Checks target IP reputation against a global database of reported SSH attacks, spam, and brute-force actors.

🛡️ AbuseIPDB API | Real-time | Intel-Driven

🕵️

Data Breach Checker (OSINT)

Cross-references associated domains and emails with global data breach repositories (e.g., HaveIBeenPwned) to identify leaked credentials and compromised accounts.

🔍 OSINT Integration | Credential Leak Detection
